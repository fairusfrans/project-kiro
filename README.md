
# Smart City IoT Dashboard

## Deskripsi
Mini project Internet of Things (IoT) bertema Smart City
untuk simulasi monitoring lingkungan kota pintar melalui
dashboard berbasis web.

## Tujuan
Mendemonstrasikan visualisasi data lingkungan dan status
perangkat IoT menggunakan HTML, CSS, dan JavaScript.

## Fitur
- Monitoring suhu lingkungan (simulasi)
- Monitoring kelembapan (simulasi)
- Indikator kualitas udara (simulasi)
- Pemantauan kapasitas tempat sampah pintar
- Grafik perubahan suhu menggunakan Chart.js
- Notifikasi kondisi lingkungan
- Tampilan responsif

## Teknologi
- HTML5
- CSS3
- JavaScript
- Chart.js

## Cara Menjalankan
1. Clone atau unduh repository.
2. Buka folder project di Kiro IDE.
3. Buka index.html menggunakan browser.
4. Pastikan koneksi internet aktif untuk memuat Chart.js.

## Catatan
Data sensor pada versi ini merupakan data simulasi,
bukan pembacaan sensor fisik atau perangkat IoT nyata.

## Pengembangan Selanjutnya
Dashboard dapat dikembangkan dengan integrasi ESP32,
sensor lingkungan, MQTT, dan database untuk data nyata.
